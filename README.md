# 每天一个字 · 新华字典解读选题库

为小红书「每天解读一个字，持续365天」准备的500字候选库。

## 内容入口

- [完整候选库：人群、词语入口、切入角度](output/hanzi-500/500字候选库.md)
- [500字简洁总览](output/hanzi-500/500字总览.md)
- [结构化JSON](output/hanzi-500/500字候选库.json)
- [候选原稿：编辑源文件](output/hanzi-500/候选原稿.txt)

共500个不重复的字、20个主题，每组25字，标记30个优先试写字。词语入口和切入角度属于编辑建议；正式写作前需核对《新华字典》的具体版本、读音和义项，并补入真实经历。

## 在另一台电脑继续

1. 从远程仓库页面复制克隆地址，使用 `git clone <仓库地址>` 下载项目。
2. 在编辑器或Codex中打开下载后的项目目录。
3. 每次开始编辑前，在项目目录运行 `git pull --ff-only`。
4. 编辑完成后提交并推送；换电脑前确认推送成功。

```sh
git add README.md output/hanzi-500
git commit -m "更新汉字选题库"
git push
```

两台电脑避免同时修改同一份文件；若拉取提示冲突，先处理冲突，不要强制推送覆盖另一台的内容。远程仓库同步的是已提交并推送的项目文件，不包含本地聊天记录。

## 修改与生成

只阅读或编辑Markdown不需要安装依赖。重新生成整套候选库需要Python 3，仅使用标准库：

```sh
python3 output/hanzi-500/生成候选库.py
```

源文件是 `output/hanzi-500/候选原稿.txt`，每组以 `@编号|主题|共鸣人群` 开头，每条为 `字|词语入口|切入角度`。优先试写名单与说明文字在生成脚本中维护。

生成脚本会覆盖完整Markdown、总览、JSON和校验结果。因此，长期保留的内容修改应写入原稿或生成脚本，再运行生成命令。生成时会检查500字、全库去重、20组各25字以及字段完整性。

此仓库首批内容仅包含本项目选题库和说明文件。
